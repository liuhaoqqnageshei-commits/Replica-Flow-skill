流程与方法

检查输入，建立任务状态✦

一次可靠的复刻，从读懂已有资料开始

给出一个网址，还不足以说明页面是如何工作的。ReplicaFlow 会先打开你提供的源码、网页归档和截图，确认哪些资料可以直接使用、哪些状态还需要补采集。已经说清的内容和设备范围会被记录下来，让后续工作沿着同一个方向推进，也让跨轮继续时不必从头解释。

先采集，再理解页面的设计

一张长截图能告诉我们页面的样子，却未必能解释它如何变化。这个阶段会沿着入口、组件、样式和动画调用读取源码，再与原站画面交叉核对。布局、字体、颜色、滚动区间和隐藏状态都会整理成具体规格；没有查清的值会保留为待测，而不是用猜测补成事实。

阅读更多

完整报告确认后，再开始构建

让范围、内容和限制在同一份方案里对齐

开始写页面之前，ReplicaFlow 会展示一份完整分析报告：原站如何组织内容，设计参数来自哪里，每个区域要替换成什么，哪些细节仍有证据限制，以及准备怎样实现和验收。你确认这份报告，就同时完成共同理解和构建批准。之后按方案自主推进，局部修改不再重复审批。

阅读更多

整理素材，建立设计系统

先统一规则，再让每个区域落到同一张页面里

新的内容与图片，需要放进原站的结构里，而不是把结构改成另一套模板。报告确认后，先建立资产映射，再整理颜色、字体、网格、按钮和集中内容数据。图片的比例、主体方向、裁切锚点与留白都有对应位置；中文内容则按文字框、层次和密度逐段校准。

阅读更多

按章节构建，一轮一轮修正

不是把整页写完，再凭印象说一句“很像”。ReplicaFlow 按确认的章节顺序推进，每节完成后就在相同视口和状态下截图，与参考并排查看，同时保留原尺寸检查。先处理结构、边界与比例，再调整字体、裁切和动效；能证实并修复的差异会先修正，再进入下一节。

质量验收与完整交付

能打开、能使用，也能说明哪里还没验证

页面看起来完成，不代表工作已经结束。导航、搜索、弹层、下载和每个实际存在的控件，都需要用真实操作核验；还要检查构建、控制台、图片加载和减少动态等降级情况。交付包含源码、预览、生成素材、提示词、分析、对照图和剩余差异，让结果可打开，也可继续修改。

为什么要先读源码？

把“看起来像”变成有依据的实现

同一个画面，背后可能是静态图片、Canvas 绘图，也可能是滚动驱动的时间轴。只看截图容易选错实现方式，进而丢失交互、放大性能成本。ReplicaFlow 先追踪源码，再用真实画面交叉核验，让能查到的参数落到证据上，也让尚未查清的部分保持透明。

三个内部模块，如何一起工作

ReplicaFlow 内部包含需求澄清、设计拆解和质量评审三个模块。它们分别处理真正影响方案的选择、原站的布局与交互规格，以及最终页面的整体质量。模块沿着同一份任务记录工作：先找到证据和基准，再逐节构建、对照与修正。

让生成图片融入原来的页面

比例、裁切、主体与留白，比“好看”更具体

替换图片最常见的问题，不是画面不够漂亮，而是它的构图和原来的位置不匹配。人物朝向变了、主体太大、留白不足，都可能让同样的布局显得失衡。ReplicaFlow 按每张图的实际用途制定生成要求，保留原图、优化版和提示词，并在页面中检验真实的裁切效果。

阅读更多

看懂动画，再重建交互

触发、轨迹、时长与反向行为，都要有依据

鼠标进入后才出现的按钮，滚动到某处才开始的转场，以及会随指针改变方向的线段，都不是一张截图能说明白的。ReplicaFlow 先读动画调用和真实参数，再采集相应状态。复杂动画会单独拆解时间轴，没有连续录屏时就明确验证边界，不把关键帧拼图称为真实录屏。

阅读更多

用并排对照，找到真正的差异

原站是英文，复刻内容换成中文；原人物被新的生成角色替换，这些变化本来就是计划的一部分。视觉验收应该先比较网格、边界、文字框、图片框和章节留白，再分析内容带来的偏移。ReplicaFlow 保留每一轮截图与差异记录，让修复有明确对象，也让剩余限制可被看见。

准备好资料，开始一次复刻

Read the source. Rebuild the experience.

先完成本地安装，再把目标网址、可读源码或网页归档、参考 PNG 和内容替换要求放在一起，就可以启动 ReplicaFlow。先把已有决定告诉它，接下来由流程核查资料、补采集、分析并展示报告。确认方案后再构建，最后拿到的不只有一个页面，还有能继续修改的工程、素材、对照图和清楚的差异记录。

下载技能，安装到本地 Agent

完整下载 → 放入技能目录 → 选择 ReplicaFlow

把 ReplicaFlow 下载到本地，让你的 Agent 使用同一套复刻流程。完整技能包包含入口文件、需求澄清、设计拆解和质量评审三个内部模块，以及分析与验收参考。不需要另外寻找其他技能；安装之后，选择 ReplicaFlow，提供网址和参考资料，就能开始。
