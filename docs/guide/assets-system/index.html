整理素材，建立设计系统

先统一规则，再让每个区域落到同一张页面里

阶段 04 ／ 素材来自 ReplicaFlow 的工作流说明

新的内容与图片，需要放进原站的结构里，而不是把结构改成另一套模板。报告确认后，先建立资产映射，再整理颜色、字体、网格、按钮和集中内容数据。图片的比例、主体方向、裁切锚点与留白都有对应位置；中文内容则按文字框、层次和密度逐段校准。

#资产不是随便替一张图

记录每个原图位置对应的替换文件、尺寸、比例、主体方向、留白和亮度。背景装饰、人物、视频、纹理和模型要分别判断。

用户指定生图时，先定代表性画风，再制作独立资产；保存生成原图、优化版、提示词和实际使用位置。图片内文案交给真实 DOM。

#把设计规则集中起来

建立 CSS 变量或相应设计 token，整理网格、间距、字体、按钮和标题。集中内容和媒体数据，让不同页面共享同一套规则。

按已经确认的技术栈实现；保留参考材料和已有有效工程。原站生产 bundle 用来取证，不作为复刻成品直接运行。

#让中文适配原来的密度

中文字形、标点和断行会改变视觉重量。按文字框、行数、层次和密度校准，而不是机械替换字符串。

字体缺字时明确回退。身份、项目和成果只使用真实资料，不为了填满页面虚构数据。

留意这个细节

一张生成的静态图片，不等于已经替换视频或交互动画。素材类型与真实能力要对应。

带走这份清单

  • 原位置与替换资产一一对应
  • 保存提示词、原图和优化版
  • 集中维护颜色、字体和布局规则
  • 图片失败时如实保留占位记录
